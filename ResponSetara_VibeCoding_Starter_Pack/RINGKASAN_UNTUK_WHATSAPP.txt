PERUBAHAN SCOPE

STACK FINAL
- Laravel 13
- React 19 + TypeScript
- Official Laravel React Starter Kit
- Inertia + Vite + Tailwind
- Supabase PostgreSQL
- Laravel Authentication khusus admin
- Gemini API melalui backend
- Web Speech API untuk TTS dan STT
- TailAdmin Free React untuk template dashboard admin

KENAPA SUPABASE
Data kategori, kondisi, bantuan, frasa, panduan, dan kontak
bersifat relasional. Supabase menggunakan PostgreSQL sehingga
cocok dengan migration dan Eloquent Laravel.

DATASET
- Dataset utama berupa seed CMS yang sudah disiapkan.
- Mozilla Common Voice Indonesia hanya untuk pengembangan STT
  lanjutan, bukan kebutuhan MVP.
- Data BNPB opsional untuk statistik dan edukasi.
- Kontak darurat dikelola admin dan diverifikasi berkala.

CARA MENGURANGI HALUSINASI AI
- Laravel membuat template lebih dulu.
- Data sensitif diganti placeholder.
- AI hanya merapikan kalimat.
- Output wajib JSON.
- Backend memvalidasi fakta dan placeholder.
- Jika AI gagal, aplikasi memakai template.
- Pesan dan transkripsi tidak disimpan.
